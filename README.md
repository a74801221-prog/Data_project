# Data_project
## Data Project - Group 1: Descriptive Analysis

##  هدف المشروع (Objective)
هذا المستودع يمثل مخرجات **المجموعة الأولى** الخاصة بالتحليل الوصفي (Descriptive Analysis) لبيانات أداء الطلاب (`student_data.csv`).

##  محتويات المستودع (Repository Contents)
- **`student_data.csv`**: ملف البيانات الأساسي المستخدم في التحليل.
- **`Group1_Descriptive_Analysis.ipynb`**: كود جوبيتر نوت بوك الذي يحتوي على خطوات المعالجة والتحليل الإحصائي باستخدام بايثون (Pandas).
- **`Group1_Final_Report.xlsx`**: التقرير الإحصائي النهائي بصيغة Excel ويحتوي على جداول الإحصائيات الوصفية.

## أبرز النتائج الإحصائية (Key Findings)
- **حجم البيانات:** يحتوي الملف على بيانات لـ **395 طالباً** مع كافة المتغيرات الرقمية والفئوية.
- **الإحصائيات الوصفية:** تم استخراج المتوسط (`Mean`)، والانحراف المعياري (`Std`)، والقيم الصغرى والعليا (`Min` / `Max`) لكل متغير (مثل درجات G1, G2, G3 وأوقات الدراسة).
- **ملاحظات هامة:** تم رصد قيم شاذة (`Outliers`) واضحة في متغير الغياب (`absences`) حيث بلغ الحد الأقصى للغياب 75 يوماً، مما يستدعي الانتباه في مراحل التحليل القادمة.
